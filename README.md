# Mamaearth Returns & Growth Intelligence Pipeline

A reproducible SQLite + Pandas + visualization + GenAI pipeline for analyzing order returns, revenue quality, payment-method risk, and monthly revenue trends.

## Repository structure

```text
.
├── data/                         # Original CSVs; do not manually clean them
├── sql/
│   ├── schema.sql                # SQLite tables and constraints
│   ├── seed_data.sql             # CSV import/seed loader
│   └── reports.sql               # Required raw-data SQL reports
├── analysis/
│   ├── clean_and_eda.py          # Independent Pandas cleaning, EDA, findings export
│   └── visualize.py              # Rebuilds both PNG charts from raw CSVs
├── visualizations/               # Generated PNGs
└── narrator/
    ├── findings.json             # Generated by clean_and_eda.py (do not hand-edit)
    ├── generate_narrative.py     # Gemini SCR narrative + offline fallback + numeric checker
    └── sample_output.txt         # Saved narrative used for the numeric acceptance check
```

## Requirements

Python 3, pandas, matplotlib. For the optional online narrative, install `google-genai` and use a free-tier Google AI Studio Gemini API key. The offline path works without an API key or network access.

```bash
python3 -m pip install pandas matplotlib
# Optional, for Gemini only:
python3 -m pip install google-genai
```

## Run order (fresh SQLite database)

Run commands from the repository root. The SQLite commands below are for a **fresh** database. The report script adds `loyalty_tier`, so do not run schema/seed/reports repeatedly against the same already-populated database.

```bash
rm -f mamaearth.db
sqlite3 mamaearth.db < sql/schema.sql
sqlite3 mamaearth.db < sql/seed_data.sql
sqlite3 mamaearth.db < sql/reports.sql
```

Check the seed counts with:

```bash
sqlite3 mamaearth.db "SELECT (SELECT COUNT(*) FROM customers), (SELECT COUNT(*) FROM products), (SELECT COUNT(*) FROM orders);"
```

Expected counts: `45, 16, 180`. The SQL reports use raw, uncleaned orders; keep their totals separate from the cleaned Pandas totals.

## Run the Python cleaning and EDA layer

```bash
python3 analysis/clean_and_eda.py
```

This script reads `data/customers.csv`, `data/products.csv`, and `data/orders.csv` directly; it does not depend on SQLite. It prints each required intermediate result, removes five duplicate rows, imputes missing values, flags quantity outliers without deleting them, evaluates return-rate hypotheses and segments, and computes monthly revenue both with and without outliers. At the end of Part 2 Task 5/EDA, it automatically writes `narrator/findings.json`. **Do not hand-edit this JSON**; rerun the script to regenerate it from the source CSVs.

## Regenerate visualizations

```bash
python3 analysis/visualize.py
```

This writes `visualizations/return_rate_by_payment.png` and `visualizations/monthly_revenue_trend.png`. The monthly chart uses the outlier-corrected series, where March 2026 is the genuine peak.

## Generate the SCR narrative (Gemini or offline)

The script uses the Gemini API only if a key is available. Google AI Studio offers a free usage tier; use a free-tier key, and do not configure a paid-only key for this project. Never commit your key to GitHub.

Optional online run (bash):

```bash
export GEMINI_API_KEY="YOUR_FREE_TIER_KEY"
python3 narrator/generate_narrative.py
unset GEMINI_API_KEY
```

If you do not set a key, the same command automatically uses the deterministic offline fallback—no network access or API spending required:

```bash
python3 narrator/generate_narrative.py
```

The script prints the Situation–Complication–Resolution narrative, checks all five required numeric facts, and saves the exact narrative used to `narrator/sample_output.txt`. The sample is regenerated on each run. A failed online call also triggers the offline fallback.

## Full reproducibility sequence

After setting up a fresh SQL database once, run these from the repository root in order:

```bash
python3 analysis/clean_and_eda.py
python3 analysis/visualize.py
python3 narrator/generate_narrative.py
```

The expected key findings are cleaned revenue ₹97,358.30; raw SQL revenue ₹99,860.20; duplicate-driven difference ₹2,501.90; COD return rate 44.4%; highest-risk segment COD + Tier-2 at 54.5%; and outlier-corrected peak month March 2026 at ₹20,318.90. These are descriptive findings, not causal or formal statistical-significance claims.
